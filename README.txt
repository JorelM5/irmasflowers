IRMA'S FLOWERS — ARCHIVOS PARA NETLIFY Y GITHUB

1. Descomprima el ZIP.
2. Suba a la raíz del repositorio todo el contenido de esta carpeta, no la carpeta exterior.
3. Los archivos index.html, style.css, script.js y products.json deben quedar juntos.
4. Mantenga la carpeta img con todas las imágenes.

La página abre en inglés y el botón Español cambia la interfaz al español.
Las fotos y los botones de DoorDash llevan a la tienda de Irma's Flowers.
Los botones de WhatsApp preparan el mensaje para recoger en la tienda.

NETLIFY DESDE GITHUB:
Conecte el repositorio en Netlify. No necesita comando de compilación y el directorio de publicación es el directorio raíz: .

NETLIFY DROP:
También puede arrastrar directamente esta carpeta descomprimida en Netlify Drop.
